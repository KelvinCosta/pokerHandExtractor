# Security Policy

## Supported Versions

Currently, only the `main` branch (latest release) is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Security is a top priority for our Business Intelligence and Auditing systems. 

If you discover a security vulnerability within this project, **please do not open a public issue.** Public disclosure can put our users at risk before a patch is available.

Instead, please report it privately by sending an email to:
**kelvinvicentecosta@gmail.com**

### What to include in your report
- A description of the vulnerability and its impact.
- Detailed steps to reproduce the vulnerability (scripts, payloads, or screenshots are highly appreciated).
- Any potential mitigation or proposed fixes you have identified.

### What happens next?
1. We will acknowledge receipt of your vulnerability report within 2 business days.
2. We will investigate the issue and determine if it is a valid vulnerability.
3. If valid, we will work on a patch and coordinate a disclosure timeline with you.

Thank you for helping keep the poker ecosystem secure!
